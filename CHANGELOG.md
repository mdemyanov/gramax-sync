# Changelog

Все значимые изменения в проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.0] - 2025-01-03

### Добавлено
- ✅ Адаптация модели данных под реальную структуру workspace.yaml
  - Поддержка словаря sections вместо списка
  - Поддержка null значений для description и icon
  - Автоматическое преобразование в формат для использования в коде
- ✅ Команда `gramax-sync edit set-workspace-dir` для изменения директории репозиториев
- ✅ Автоматическая аутентификация при клонировании (токен добавляется в URL)
- ✅ Улучшенная обработка ошибок GitLab API с fallback на прямые HTTP запросы
- ✅ Правильная передача URL в python-gitlab (базовый URL инстанса + путь проекта)
- ✅ Обновление токена в GitLabClient после сохранения через `_reset_client()`
- ✅ Исправление пагинации при получении дерева репозиториев (получение всех элементов)

### Исправлено
- 🔧 Исправлена ошибка парсинга workspace.yaml (поддержка null значений)
- 🔧 Исправлена ошибка 401 Unauthorized при использовании токена (пересоздание клиента)
- 🔧 Исправлена ошибка пагинации (получение всех 229 элементов вместо 20)
- 🔧 Исправлена передача URL в GitLabClient (базовый URL вместо полного URL репозитория)
- 🔧 Исправлена аутентификация при клонировании (токен теперь добавляется в URL)

### Изменено
- 📝 Изменена ветка по умолчанию для репозитория конфигураций: `main` → `master`
- 📝 Улучшена документация по управлению конфигурацией
- 📝 Добавлена информация о структуре директорий для репозиториев

### Документация
- 📚 Обновлён README.md с актуальной информацией
- 📚 Добавлена информация о команде `edit set-workspace-dir`
- 📚 Обновлены примеры использования с правильной веткой `master`
