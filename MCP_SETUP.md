# Настройка MCP сервера для Claude Desktop

Это руководство поможет настроить MCP сервер gramax-sync для использования в Claude Desktop.

## 📋 Предварительные требования

1. **Установленный gramax-sync**
   ```bash
   pip install -e ".[dev]"
   ```

2. **Настроенная конфигурация**
   - Выполните `gramax-sync init` для первоначальной настройки
   - Или убедитесь, что конфигурация существует в `~/.config/gramax-sync/config.yaml`

3. **Claude Desktop** установлен и запущен

## 🔧 Настройка MCP сервера

### Шаг 1: Определите путь к Python

Найдите путь к Python, который используется для gramax-sync:

```bash
# Если используете виртуальное окружение
which python
# или
which python3

# Пример вывода:
# /Users/username/.venv/bin/python
# или
# /usr/local/bin/python3
```

### Шаг 2: Найдите путь к проекту

Определите абсолютный путь к директории проекта gramax-sync:

```bash
cd /path/to/gramax-sync
pwd

# Пример вывода:
# /Users/username/CursorProjects/gramax-sync
```

### Шаг 3: Настройте конфигурацию Claude Desktop

Откройте файл конфигурации Claude Desktop:

**macOS:**
```bash
open ~/Library/Application\ Support/Claude/claude_desktop_config.json
```

**Windows:**
```
%APPDATA%\Claude\claude_desktop_config.json
```

**Linux:**
```bash
~/.config/Claude/claude_desktop_config.json
```

### Шаг 4: Добавьте конфигурацию MCP сервера

Добавьте следующую конфигурацию в файл `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "gramax-sync": {
      "command": "python",
      "args": ["-m", "gramax_sync.mcp"],
      "env": {
        "GRAMAX_WORKSPACE_PATH": "/path/to/workspace.yaml",
        "GRAMAX_WORKSPACE_DIR": "/path/to/repos"
      }
    }
  }
}
```

**Важно:** Замените пути на ваши реальные значения:

- `"command"`: путь к Python (из шага 1)
- `"args"`: оставьте как есть, если gramax-sync установлен в режиме разработки
- `"GRAMAX_WORKSPACE_PATH"`: путь к файлу workspace.yaml (опционально, если конфигурация уже настроена)
- `"GRAMAX_WORKSPACE_DIR"`: путь к директории с репозиториями (опционально)

### Пример полной конфигурации

```json
{
  "mcpServers": {
    "gramax-sync": {
      "command": "/Users/username/.venv/bin/python",
      "args": ["-m", "gramax_sync.mcp"],
      "env": {}
    }
  }
}
```

**Примечание:** Если конфигурация gramax-sync уже настроена через `gramax-sync init`, переменные окружения `GRAMAX_WORKSPACE_PATH` и `GRAMAX_WORKSPACE_DIR` не обязательны. MCP сервер автоматически загрузит конфигурацию из `~/.config/gramax-sync/config.yaml`.

### Шаг 5: Перезапустите Claude Desktop

После изменения конфигурации необходимо перезапустить Claude Desktop, чтобы изменения вступили в силу.

## ✅ Проверка настройки

После перезапуска Claude Desktop:

1. Откройте Claude Desktop
2. В интерфейсе Claude должны быть доступны инструменты gramax-sync
3. Попробуйте использовать инструмент `list_repositories` для проверки

## 🛠️ Доступные MCP инструменты

После настройки в Claude Desktop будут доступны следующие инструменты:

### 1. `list_repositories`
Показать все секции и каталоги из workspace.yaml.

**Параметры:**
- `section` (опционально): Фильтр по секции (glob pattern)

**Пример использования:**
```
Покажи список всех репозиториев
Покажи репозитории в секции "1-*"
```

### 2. `get_repository_status`
Показать git статус репозиториев.

**Параметры:**
- `section` (опционально): Фильтр по секции (glob pattern)
- `catalog` (опционально): Конкретный каталог

**Пример использования:**
```
Покажи статус всех репозиториев
Покажи статус репозиториев в секции "1-методология"
```

### 3. `clone_repositories`
Клонировать репозитории из workspace.yaml.

**Параметры:**
- `section` (опционально): Фильтр по секции (glob pattern)

**Пример использования:**
```
Клонируй все репозитории
Клонируй репозитории в секции "1-*"
```

### 4. `pull_repositories`
Обновить репозитории (git pull).

**Параметры:**
- `section` (опционально): Фильтр по секции (glob pattern)
- `catalog` (опционально): Конкретный каталог

**Пример использования:**
```
Обнови все репозитории
Обнови репозиторий "ritm-methodology"
```

### 5. `commit_changes`
Закоммитить изменения в репозиториях.

**Параметры:**
- `message` (опционально): Сообщение коммита (автогенерация если не указано)
- `section` (опционально): Фильтр по секции (glob pattern)
- `catalog` (опционально): Конкретный каталог

**Пример использования:**
```
Закоммить все изменения
Закоммить изменения с сообщением "Update documentation"
```

### 6. `push_changes`
Отправить изменения в remote (git push).

**Параметры:**
- `section` (опционально): Фильтр по секции (glob pattern)
- `catalog` (опционально): Конкретный каталог

**Пример использования:**
```
Отправь все изменения в remote
Отправь изменения в секции "1-методология"
```

### 7. `sync_repositories`
Полная синхронизация: pull → commit → push.

**Параметры:**
- `section` (опционально): Фильтр по секции (glob pattern)
- `message` (опционально): Сообщение коммита

**Пример использования:**
```
Синхронизируй все репозитории
Синхронизируй репозитории в секции "1-*"
```

## 🔍 Устранение неполадок

### MCP сервер не запускается

1. **Проверьте путь к Python:**
   ```bash
   /path/to/python -m gramax_sync.mcp
   ```
   Должен запуститься без ошибок (будет ждать ввода через STDIO)

2. **Проверьте установку fastmcp:**
   ```bash
   pip list | grep fastmcp
   ```
   Если не установлен:
   ```bash
   pip install fastmcp
   ```

3. **Проверьте конфигурацию:**
   Убедитесь, что конфигурация gramax-sync существует:
   ```bash
   ls ~/.config/gramax-sync/config.yaml
   ```

### Инструменты не отображаются в Claude Desktop

1. **Проверьте логи Claude Desktop:**
   - macOS: `~/Library/Logs/Claude/`
   - Windows: `%APPDATA%\Claude\logs\`
   - Linux: `~/.config/Claude/logs/`

2. **Проверьте синтаксис JSON:**
   Убедитесь, что файл `claude_desktop_config.json` содержит валидный JSON

3. **Перезапустите Claude Desktop:**
   Полностью закройте и снова откройте приложение

### Ошибки при выполнении инструментов

1. **Конфигурация не найдена:**
   ```
   ❌ Ошибка: Конфигурация не найдена...
   ```
   Решение: Запустите `gramax-sync init` для первоначальной настройки

2. **Репозитории не найдены:**
   ```
   ⚠️  Нет репозиториев, соответствующих фильтру
   ```
   Решение: Проверьте фильтры или выполните `clone_repositories`

3. **Ошибки аутентификации:**
   ```
   ❌ Ошибка: Токен не найден
   ```
   Решение: Выполните `gramax-sync auth login` для аутентификации

## 💡 Советы по использованию

1. **Начните с простых операций:**
   - Используйте `list_repositories` для просмотра доступных репозиториев
   - Используйте `get_repository_status` для проверки статуса

2. **Используйте фильтрацию:**
   - Фильтруйте по секциям для работы с конкретными группами репозиториев
   - Используйте glob patterns: `"1-*"`, `"*-методология"`

3. **Синхронизация:**
   - Используйте `sync_repositories` для полной синхронизации всех репозиториев
   - Это эквивалентно выполнению pull → commit → push для всех репозиториев

4. **Безопасность:**
   - Все операции выполняются с теми же правами, что и CLI команды
   - Убедитесь, что у вас есть необходимые права доступа к репозиториям
