# Дорожная карта развития gramax-sync

## Текущий статус

**Версия:** 0.1.0 (MVP)
**Статус:** Готов к использованию

Все основные функции реализованы:
- CLI команды: init, auth, edit, update, clone, status, pull, commit, push, sync
- OAuth и PAT аутентификация
- MCP Server для Claude Desktop
- Тестовое покрытие ~67%
